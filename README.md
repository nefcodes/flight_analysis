# ✈️ Flight Data Analysis Portfolio

A collection of data analysis projects exploring flight pricing experiments, airline booking patterns, and marketing channel performance using Excel and SQL.

The projects demonstrate practical applications of data analysis, data exploration, business intelligence, and analytical problem-solving.

## 📂 Projects

### 1. Flight Pricing Experiment Analysis — Excel

**Folder:** `Project1_Flight_Pricing_Test_Excel/`

An analysis of a flight pricing experiment using Microsoft Excel.

**Focus areas:**
- Exploring flight pricing data
- Comparing pricing experiment results
- Identifying pricing patterns
- Interpreting results to support business decisions

**Tools:** Microsoft Excel

[View Project →](./Project1_Flight_Pricing_Test_Excel/)

### 2. Flights Channel Analysis — SQL

**Folder:** `Project2_Flights_Channel_Analysis_SQL/`

A SQL-based analysis of flight marketing and booking channel data, focusing on extracting insights through structured queries.

**Focus areas:**
- Database schema exploration
- Data querying and analysis
- Marketing channel performance
- Comparing booking channel metrics
- Extracting business insights using SQL

**Tools:** SQL, SQLite

**Project files:**
- `01_schema_and_data.sql` — Database schema and data preparation
- `02_analysis_queries.sql` — Analytical SQL queries
- `flights_marketing.db` — SQLite database

[View Project →](./Project2_Flights_Channel_Analysis_SQL/)
